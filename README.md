# eranltd plugins

Claude Code plugins by [Eran Peled](https://github.com/eranltd).

```
/plugin marketplace add eranltd/claude-plugins
```

| Plugin | What it does | Install |
|---|---|---|
| [kiss](https://github.com/eranltd/kiss) | `/kiss <topic>` turns any tech topic into one plain HTML page: the whole flow at a glance, then zooms with the real names. | `/plugin install kiss@eranltd` |
| [pixel-pet](https://github.com/eranltd/pixel-pet) | Bit, a pixel puppy above your prompt: every session on your machine, plan progress, PR and CI status, and a Slack inbox. | `/plugin install pixel-pet@eranltd` |

Each plugin lives in its own repo. This one only lists them.
